概述

第二个实战：memory-lite——跨会话记忆插件。对标社区热门插件 flymysql/dsh-memory（remember/recall/forget + 每轮提示注入）、ICCuse/dsh-file-memory（文件型工作记忆）、Phant0Meow/dsh-memory-meow（项目级记忆）。核心能力：

  • 三个工具：memory_remember / memory_recall / memory_forget，模型可主动存取；
  • 被动捕获：监听会话事件，用户消息里出现「记住：xxx」时自动存档——即使模型忘了调用工具，记忆也不丢；
  • 人类可读镜像：记忆同时写入 MEMORY.md，可直接手工编辑。

应用场景：跨会话记住「部署必须走 canary 流程」「这个项目的测试命令是 pnpm test」这类事实，不用每次重述。

1.2 架构

┌──────────────────────────────────────────────────┐
│ memory-lite                                       │
│                                                  │
│  ctx.on('session/event') ──▶ 被动捕获（记住：…）    │
│         │                            │           │
│         ▼                            ▼           │

│  remember / recall / forget      │               │
│                          ┌───────┴────────┐      │
│                          ▼                ▼      │
│                    memories.json      MEMORY.md   │
│                    （权威）          （人类镜像）   │
└──────────────────────────────────────────────────┘

设计决策：

  • JSON 为权威存储，MEMORY.md 每次写入时全量重建——避免双写不一致；
  • 召回打分用词重叠 + 新近度加权，不引入 BM25（记忆库条目少，简单可解释更重要）；
  • 被动捕获用防御式解析（详见第五节），因为事件载荷结构以当前版本为准。

 43export class MemoryStore {
 44  constructor(private data: MemData, private file: string) {}
 45
 46  static async open(file: string): Promise<MemoryStore> {
 47    let data: MemData = { version: 1, items: [] }
 48    try {
 49      data = JSON.parse(await readFile(file, 'utf8')) as MemData
 50    } catch {
 51      /* 首次使用 */
 52    }
 53    return new MemoryStore(data, file)
 54  }
 55
 56  add(content: string, category: string, tags: string[], origin: Memory['origin'], maxItems: number): Memory {
 57    const item: Memory = {
 58      id: `mem_${Date.now().toString(36)}${Math.random().toString(36).slice(2, 6)}`,
 59      content: content.trim(),
 60      category: category || 'general',
 61      tags,
 62      createdAt: new Date().toISOString(),
 63      origin,
 64    }
 65    // 去重：内容完全相同则刷新而非新增
 66    const dup = this.data.items.find((m) => m.content === item.content)
 67    if (dup) {
 68      dup.createdAt = item.createdAt
 69    } else {
 70      this.data.items.push(item)
 71    }
 72    // 超上限淘汰最旧
 73    if (this.data.items.length > maxItems) {
 74      this.data.items = this.data.items.slice(-maxItems)
 75    }
 76    return dup ?? item
 77  }
 78
 79  remove(id: string): boolean {
 80    const before = this.data.items.length
 81    this.data.items = this.data.items.filter((m) => m.id !== id)
 82    return this.data.items.length < before
 83  }
 84
 85  search(query: string, topK: number) {
 86    const q = terms(query)
 87    const now = Date.now()
 88    const scored = this.data.items
 89      .map((m) => {
 90        const t = terms(m.content)
 91        const overlap = q.filter((x) => t.includes(x)).length
 92        if (overlap === 0) return null
 93        const coverage = overlap / Math.max(1, q.length)
 94        // 新近度加权：30 天半衰期
 95        const ageDays = (now - new Date(m.createdAt).getTime()) / 86400000
 96        const recency = Math.pow(0.5, ageDays / 30)
 97        return { memory: m, score: Number((coverage * 0.7 + recency * 0.3).toFixed(4)) }
 98      })
 99      .filter((x): x is { memory: Memory; score: number } => x !== null)
100      .sort((a, b) => b.score - a.score)
101      .slice(0, Math.max(1, topK))
102    return scored
103  }
104
105  list() {
106    return this.data.items.map((m) => ({ ...m }))
107  }
108
109  stats() {
110    return { items: this.data.items.length, categories: new Set(this.data.items.map((m) => m.category)).size }
111  }
112
113  /** 序列化为人类可读的 Markdown 镜像 */
114  toMarkdown(): string {
115    const lines = ['# MEMORY', '']
116    const byCat = new Map<string, Memory[]>()
117    for (const m of this.data.items) {
118      if (!byCat.has(m.category)) byCat.set(m.category, [])
119      byCat.get(m.category)!.push(m)
120    }
121    for (const [cat, items] of byCat) {
122      lines.push(`## ${cat}`, '')
123      for (const m of items) {
124        const tags = m.tags.length ? ` \`${m.tags.join('` `')}\`` : ''
125        lines.push(`- [${m.id}]${tags} ${m.content}`)
126      }
127      lines.push('')
128    }
129    return lines.join('\n')
130  }
131
132  async flush(): Promise<void> {
133    await mkdir(dirname(this.file), { recursive: true })
134    const md = join(dirname(this.file), 'MEMORY.md')
135    const tmpJ = `${this.file}.${process.pid}.tmp`
136    await writeFile(tmpJ, JSON.stringify(this.data))
137    await rename(tmpJ, this.file)
138    const tmpM = `${md}.${process.pid}.tmp`
139    await writeFile(tmpM, this.toMarkdown())
140    await rename(tmpM, md)
141  }
142}
143
144/** 轻量词项提取：拉丁词 + 中文二元组，去停用词 */
145function terms(text: string): string[] {
146  const out: string[] = []
147  const lower = text.toLowerCase()
148  for (const m of lower.matchAll(/[a-z0-9][a-z0-9_.+-]*/g)) out.push(m[0])
149  let run = ''
150  const flush = () => {
151    if (!run) return
152    if (run.length === 1) out.push(run)
153    else for (let i = 0; i + 1 < run.length; i++) out.push(run.slice(i, i + 2))
154    run = ''
155  }
156  for (const ch of lower) {
157    if (/[\u3400-\u4dbf\u4e00-\u9fff\uf900-\ufaff]/.test(ch)) run += ch
158    else flush()
159  }
160  flush()
161  return out.filter((t) => !STOPWORDS.has(t) && t.length > 1)
162}

126function splitTags(tags?: string): string[] {
127  if (!tags) return []
128  return tags
129    .split(/[,，]/)
130    .map((t) => t.trim())
131    .filter(Boolean)
132}

要点：

  • memory_forget 的入参 id 来自 recall 的结构化字段，不是从自然语言里解析——这正是第 005 篇「规范值」契约的落地；
  • 去重逻辑：相同内容刷新时间而非重复入库；
  • 每次写操作后 flush() 双写 JSON + MEMORY.md。

四、被动捕获：监听 session/event

被动捕获是记忆插件区别于普通存储工具的关键：用户在对话里说「记住：xxx」，即使模型没有调用工具，也自动存档。

先纠正两个会导致"监听不到 / 读到错东西"的事实：

  1. session/event 的回调签名是 (session, event)——第一个参数是 Session 对象，第二个才是事件。写成 (event) => … 会把 Session 当事件用，event.type 永远是 undefined（Cordis 的 dispatch 直接把 [session, event] 作为回调实参，见 dsh-session/lib/index.js 的发布点）。
  2. 用户消息的会话事件类型是 user/message（surface 事件家族：system/message、developer/message、user/message、assistant/message、tool/result）。turn/*、step/*、tool/call 是持久化会话事件类型，不是同名 Cordis 事件——只能从 session/event 里按 type 过滤。
 1// 在 apply() 内追加
 2if (config.captureEnabled) {
 3  ctx.on('session/event', (session, event: any) => {
 4    if (!isUserMessage(event)) return          // ← 先按 type 收窄，别解析所有事件
 5    const text = extractText(event)
 6    if (!text) return
 7    const m = text.match(/(?:记住|remember)[:：]\s*(.{2,200})/i)
 8    if (!m) return
 9    void (async () => {
10      const s = await ready()
11      s.add(m[1].trim(), 'captured', [], 'passive', config.maxItems)
12      await s.flush()
13      console.log(`[memory-lite] captured: ${m[1].slice(0, 40)}`)
14    })()
15  })
16}
17
18/** 只认 user/message（事件类型是封闭联合，没有下划线变体） */
19function isUserMessage(event: any): boolean {
20  return event?.type === 'user/message'
21}
22
23/**
24 * user/message 的 `event.data` 就是一条 MessageBase：
25 *   { id: MessageId, role: 'user', content: readonly ContentBlock[], source: MessageSource }
26 * ContentBlock 是联合：text / image / file / reasoning / tool-call / tool-addition / tool-removal；
27 * 文本块形如 { type: 'text', text: string }。
28 */
29function extractText(event: any): string | null {
30  const content = event?.data?.content
31  if (typeof content === 'string') return content          // 兼容早期 v0 会话
32  if (!Array.isArray(content)) return null
33  return content
34    .filter((b: any) => b?.type === 'text')
35    .map((b: any) => b.text as string)
36    .join('')
37}

工程建议：第一次接入某个事件时，先只打印不处理——ctx.on('session/event', (session, e) => console.dir(e, { depth: 4 }))，跑一轮真实会话看清结构。注意打印的第一个参数是 Session，别把 session 当成载荷的一部分。

还有两个相关事件值得知道：session/flush（持久化排空时机，适合做"落盘后同步镜像"）、agent/inbox/*（消息被领取/丢弃，适合做"未读"语义）。它们的签名同样以各自包的 README 为准。

五、注入扩展点：先打印，后处理

社区插件有两种让记忆「主动可见」的思路：

45  const md = s.toMarkdown()
46  assert.match(md, /# MEMORY/)

八、与社区插件的对照

插件机制memory-lite 的取舍
flymysql/dsh-memory三工具 + 每轮注入 + 设置页工具一致；注入留作扩展点（默认关）
ICCuse/dsh-file-memory会话笔记文件，抗上下文压缩可扩展：recall 结果写入会话笔记
futongxu9-maker/dsh-shared-memoryMEMORY.md 注入系统提示MEMORY.md 已生成；注入待事件契约确认后开启
modusensus/dsh-mnemeSQLite + Markdown 镜像 + 后台巩固存储可换 SQLite；巩固可作后台任务（第 009 篇）

九、扩展方向

  1. 项目隔离：dataDir 设为 <workspace>/.memory/，每个项目独立记忆（对标 dsh-memory-meow）；
  2. 后台巩固：把「去重/合并/冲突裁决」做成后台任务（第 009 篇的 ctx.jobs 模式）；
  3. 引用式记忆：召回结果带 (sessionId, eventRange) 引用，可展开回原始日志（对标 Jesse-njx/dsh-memory）；
  4. 压缩抗丢：把关键记忆同步进会话笔记文件，无损挺过上下文压缩（对标 ICCuse/dsh-file-memory）；
  5. 安全加固：记忆可能含敏感信息，读写过策略钩子脱敏（第 009 篇）。

十、练习

  1. 给 memory_recall 增加 category 过滤参数，并更新测试；
  2. 实现 memory_list(category?) 工具，返回全部条目（带分页参数 offset/limit）；
  3. 把 isUserMessage / extractText 收窄：先按第四节的「只打印」方案跑一轮真实会话，根据载荷形状重写为精确判断（记得打印的是 (session, event) 两个参数）；
  4. （进阶）实现启动时若 memories.json 缺失但 MEMORY.md 存在，则从 Markdown 重建索引（- [id] \tag` content` 行的解析）。

小结

  • 记忆插件 = 三工具（结构化契约）+ 被动捕获（事件系统）+ 双写存储（JSON 权威 + MD 镜像）；
  • ctx.on('session/event', (session, event) => …)：第一个参数是 Session，写成单参数会把 Session 当事件；
  • 用户消息的事件类型是 user/message；turn/*、step/*、tool/call 是会话事件类型，不是 Cordis 事件；
  • 事件集成第一课：先打印后处理，再收窄为精确判断，失败静默；
  • 不确定的扩展点（注入）宁可留作开关，不照抄不确定的签名；
  • 召回打分保持简单可解释：词重叠 + 新近度半衰期；
  • 下一篇从单个插件走向架构：事件系统深水区、服务提供与三层能力拆分。
