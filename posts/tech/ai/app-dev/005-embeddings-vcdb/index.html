概述

Embeddings（嵌入）是连接非结构化数据与AI计算的桥梁，向量数据库则是存储和检索这些嵌入的引擎。两者结合，构成了现代AI应用中语义搜索、推荐系统、RAG等核心能力的技术基石。

本章将从词向量的基本概念出发，逐步深入到现代Embedding模型、向量数据库原理与实战，最终通过酒店推荐系统和文本抄袭检测两个项目，帮助读者掌握Embeddings与向量数据库的完整技术栈。

一、从词向量到文本嵌入

1.1 为什么需要Embedding

计算机只能处理数值，而人类语言是符号化的。Embedding的核心目标就是将语言符号映射为稠密的数值向量，使得语义相近的词在向量空间中距离也相近。

"猫" → [0.23, -0.15, 0.87, ...]  (768维)
"狗" → [0.21, -0.13, 0.85, ...]  (语义相近，向量相近)
"汽车" → [0.78, 0.42, -0.31, ...] (语义不同，向量距离远)

1.2 词向量发展历程

N-Gram语言模型

N-Gram是最早的统计语言模型，基于"一个词的出现概率只与前面N-1个词相关"的假设。

 1from collections import Counter, defaultdict
 2import math
 3
 4
 5class BigramModel:
 6    def __init__(self):
 7        self.unigram_counts = Counter()
 8        self.bigram_counts = Counter()
 9        self.vocab_size = 0
10
11    def train(self, sentences: list[str]):
12        for sentence in sentences:
13            tokens = ["<s>"] + sentence.split() + ["</s>"]
14            self.unigram_counts.update(tokens)
15            for i in range(len(tokens) - 1):
16                self.bigram_counts[(tokens[i], tokens[i + 1])] += 1
17        self.vocab_size = len(self.unigram_counts)
18
19    def probability(self, word: str, context: str) -> float:
20        bigram_count = self.bigram_counts.get((context, word), 0)
21        unigram_count = self.unigram_counts.get(context, 0)
22        if unigram_count == 0:
23            return 1.0 / self.vocab_size
24        return (bigram_count + 1) / (unigram_count + self.vocab_size)
25
26    def sentence_probability(self, sentence: str) -> float:
27        tokens = ["<s>"] + sentence.split() + ["</s>"]
28        log_prob = 0.0
29        for i in range(1, len(tokens)):
30            prob = self.probability(tokens[i], tokens[i - 1])
31            log_prob += math.log(prob)
32        return math.exp(log_prob)
33

二、向量数据库

2.1 为什么需要向量数据库

传统数据库基于精确匹配（B-Tree索引），无法处理语义相似性查询。向量数据库专为高维向量的近似最近邻搜索（ANN）设计，是AI应用的基础设施。

特性传统数据库向量数据库
查询方式精确匹配语义相似性
索引结构B-TreeHNSW / IVF
适用场景关系型数据非结构化数据检索
代表产品MySQL, PostgreSQLFAISS, Milvus, Qdrant

2.2 FAISS实战

FAISS是Meta开源的向量检索库，适合单机场景，性能极高。

 1import numpy as np
 2import faiss
 3import logging
 4
 5logging.basicConfig(level=logging.INFO)
 6logger = logging.getLogger(__name__)

 8
 9class FAISSVectorStore:
10    def __init__(self, dimension: int = 1024):
11        self.dimension = dimension
12        self.index = faiss.IndexFlatIP(dimension)
13        self.documents = []
14
15    def add_documents(self, embeddings: list[list[float]], documents: list[str]):
16        vectors = np.array(embeddings, dtype=np.float32)
17        faiss.normalize_L2(vectors)
18        self.index.add(vectors)
19        self.documents.extend(documents)
20        logger.info(f"添加文档完成，总数: {self.index.ntotal}")
21
22    def search(self, query_embedding: list[float], top_k: int = 5) -> list[tuple[str, float]]:
23        query_vector = np.array([query_embedding], dtype=np.float32)
24        faiss.normalize_L2(query_vector)
25        scores, indices = self.index.search(query_vector, top_k)
26
27        results = []
28        for score, idx in zip(scores[0], indices[0]):
29            if idx < len(self.documents) and idx >= 0:
30                results.append((self.documents[idx], float(score)))
31        return results
32
33    def save(self, path: str = "faiss_index.bin"):
34        faiss.write_index(self.index, path)
35        logger.info(f"索引已保存: {path}")
36
37    def load(self, path: str = "faiss_index.bin"):
38        self.index = faiss.read_index(path)
39        logger.info(f"索引已加载，文档数: {self.index.ntotal}")

Milvus是分布式向量数据库，适合大规模生产环境。

 9class MilvusVectorStore:
10    def __init__(self, uri: str = "milvus_demo.db", collection_name: str = "documents"):
11        self.client = MilvusClient(uri=uri)
12        self.collection_name = collection_name
13        self.dimension = 1024
14
15    def create_collection(self):
16        if self.client.has_collection(self.collection_name):
17            self.client.drop_collection(self.collection_name)
18
19        schema = self.client.create_schema(auto_id=True, enable_dynamic_field=True)
20        schema.add_field(field_name="id", datatype=DataType.INT64, is_primary=True)
21        schema.add_field(field_name="vector", datatype=DataType.FLOAT_VECTOR, dim=self.dimension)
22        schema.add_field(field_name="text", datatype=DataType.VARCHAR, max_length=2048)
23        schema.add_field(field_name="source", datatype=DataType.VARCHAR, max_length=256)
24
25        index_params = self.client.prepare_index_params()
26        index_params.add_index(
27            field_name="vector",
28            index_type="IVF_FLAT",
29            metric_type="COSINE",
30            params={"nlist": 128}
31        )
32        index_params.add_index(field_name="id", index_type="STL_SORT")
33
34        self.client.create_collection(
35            collection_name=self.collection_name,
36            schema=schema,
37            index_params=index_params
38        )
39        logger.info(f"集合 '{self.collection_name}' 创建成功")
40
41    def insert_documents(self, embeddings: list[list[float]], texts: list[str], sources: list[str]):
42        data = []
43        for emb, text, source in zip(embeddings, texts, sources):
44            data.append({
45                "vector": emb,
46                "text": text,
47                "source": source
48            })
49        self.client.insert(collection_name=self.collection_name, data=data)
50        logger.info(f"插入 {len(data)} 条文档")
51
52    def search(self, query_embedding: list[float], top_k: int = 5) -> list[dict]:
53        results = self.client.search(
54            collection_name=self.collection_name,
55            data=[query_embedding],
56            limit=top_k,
57            output_fields=["text", "source"]
58        )
59        return results[0] if results else []

四、实战项目：文本抄袭检测

4.1 项目思路

将待检测文档分句后生成Embedding，通过余弦相似度计算句子级别的语义相似性，识别潜在的抄袭片段。

4.2 完整实现

 1import dashscope
 2import numpy as np
 3import logging
 4import os
 5from dataclasses import dataclass
 6
 7logging.basicConfig(level=logging.INFO)
 8logger = logging.getLogger(__name__)

13@dataclass
14class PlagiarismMatch:
15    source_sentence: str
16    target_sentence: str
17    similarity: float
18
19
20def get_embeddings(texts: list[str]) -> list[list[float]]:
21    resp = dashscope.TextEmbedding.call(
22        model="text-embedding-v3",
23        input=texts
24    )
25    if resp.status_code == 200:
26        return [item["embedding"] for item in resp.output["embeddings"]]
27    return []

30def split_sentences(text: str) -> list[str]:
31    import re
32    sentences = re.split(r'[。！？；\n]', text)
33    return [s.strip() for s in sentences if len(s.strip()) > 5]
34
35
36class PlagiarismDetector:
37    def __init__(self, threshold: float = 0.85):
38        self.threshold = threshold
39
40    def detect(self, source_text: str, target_text: str) -> list[PlagiarismMatch]:
41        source_sentences = split_sentences(source_text)
42        target_sentences = split_sentences(target_text)
43
44        if not source_sentences or not target_sentences:
45            return []
46
47        all_sentences = source_sentences + target_sentences
48        embeddings = get_embeddings(all_sentences)
49
50        if not embeddings:
51            return []
52
53        source_embs = np.array(embeddings[:len(source_sentences)], dtype=np.float32)
54        target_embs = np.array(embeddings[len(source_sentences):], dtype=np.float32)
55
56        source_embs = source_embs / np.linalg.norm(source_embs, axis=1, keepdims=True)
57        target_embs = target_embs / np.linalg.norm(target_embs, axis=1, keepdims=True)
58
59        similarity_matrix = np.dot(source_embs, target_embs.T)
60
61        matches = []
62        for i in range(len(source_sentences)):
63            for j in range(len(target_sentences)):
64                sim = float(similarity_matrix[i][j])
65                if sim >= self.threshold:
66                    matches.append(PlagiarismMatch(
67                        source_sentence=source_sentences[i],
68                        target_sentence=target_sentences[j],
69                        similarity=sim
70                    ))
71
72        matches.sort(key=lambda x: x.similarity, reverse=True)
73        return matches

五、余弦相似度深入理解

余弦相似度是Embedding检索中最常用的度量方式，衡量两个向量方向的相似性，而非大小。

关键结论：

  • 余弦相似度范围[-1, 1]，1表示完全相同方向
  • 对向量归一化后，余弦相似度等价于点积
  • FAISS中使用IndexFlatIP（内积）+ 归一化 = 余弦相似度检索
